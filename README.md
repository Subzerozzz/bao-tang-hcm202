# Bảo tàng Tư tưởng Hồ Chí Minh

Web ôn tập tương tác: một bạn sinh viên đi dọc hành lang bảo tàng, mở từng cổng phòng, xem hiện vật và trả lời câu hỏi.

- Cả web nằm trong một file `index.html` (HTML, CSS, JS), không cần build.
- Chạy thử: mở `index.html` bằng trình duyệt.
- Deploy: import repo này vào Vercel, chọn Framework Preset là **Other**, không cần cấu hình thêm.

Nội dung biên soạn theo giáo trình Tư tưởng Hồ Chí Minh.
